云同步设置

用 GitHub Gist 在多台设备间同步「我的」收藏、备注、子分类、排序。 只有你的浏览器知道这把 token,任何时候点 GitHub 头像 → Settings → Developer settings → Tokens 都能撤销。

  1. 访问 github.com/settings/tokens/new(已为你勾好 gist 权限)
  2. 过期时间随你选 → 拉到底点 Generate token
  3. 复制以 ghp_ 开头的那串,粘到下面输入框
  4. 点「连接」。第一次会自动建一个 secret gist,后续换设备粘同一个 token 就行
